## Features

* **Flicker-Free Dual Theme System:** Seamlessly switches between a custom dark mode and a polished light mode. An inline IIFE script checks `localStorage` and system color schemes before page render to completely eliminate the white flash effect.
* **Robust CSS Design Token Architecture:** Powered entirely by CSS custom properties (`:root` and `[data-theme="light"]`) for consistent styling, colors, shadows, and spacing.
* **Atmospheric Ambient Backgrounds:** Features animated, blurred ambient color blobs and a radial-masked grid overlay for a modern, high-end tech aesthetic.
* **Interactive Elements & Micro-Interactions:** Includes a dynamic mouse-tracking cursor glow (optimized for desktop), custom scrollbars, and smooth scrolling behavior.
* **Accessibility First:** Built with keyboard navigation in mind, featuring custom focus rings, screen-reader utility classes (`.sr-only`), and an accessible skip link.
* **Optimized Typography:** Loaded with Google Fonts (**Inter** for clean UI text and **JetBrains Mono** for code and technical details) using preconnect optimizations.
